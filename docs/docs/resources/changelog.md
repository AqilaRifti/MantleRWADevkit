# Changelog

All notable changes to the Mantle RWA SDK.

## [0.1.0] - 2025-01-06

### Added

- Initial release of Mantle RWA SDK
- ERC-3643 compliant RWAToken contract
- KYCRegistry for investor verification
- YieldDistributor for dividend payments
- AssetVault for asset custody
- RWAFactory for system deployment
- TypeScript SDK with full type support
- React components (KYCFlow, InvestorDashboard, TokenMintForm, YieldCalculator)
- Comprehensive documentation

### Smart Contracts

- UUPS upgradeable proxy pattern
- Role-based access control
- Gas-optimized implementations
- Mantle Network deployment

### SDK Features

- RWAClient for initialization
- TokenModule for token operations
- KYCModule for verification
- YieldModule for distributions
- ComplianceModule for transfer restrictions

### React Components

- Dark/light theme support
- Accessibility compliance
- Customizable styling
- TypeScript support

## Upcoming

### [0.2.0] - Planned

- Additional KYC provider integrations
- Enhanced compliance reporting
- Multi-chain support
- Improved gas optimization
